Privacy policy

Effective date: October 30, 2026 · Last updated: October 30, 2026

Short version: Leetcomete does not collect, transmit, sell, or share your data. It reads the code in the current editor to produce suggestions locally in your browser. Only your preferences are stored, locally by default.

1. Scope

This policy applies to the Leetcomete browser extension for Chromium-based browsers (Chrome, Edge, Brave, and compatible browsers) and to this static website. The extension is published under the name Leetcomete.

2. What the extension does

Leetcomete adds code-completion suggestions to supported code editors on LeetCode, GeeksforGeeks, HackerRank, Codeforces, CodeChef, AtCoder, and Exercism. To do that, it reads the text of the active code editor and builds a short-lived index of identifiers in the page. The index and the source text stay inside the browser tab. They are not saved to disk by the extension and are not sent to a server.

3. Data collection and transmission

Leetcomete does not collect personal data and does not transmit source code. The extension contains no analytics, telemetry, advertising, crash-reporting SDK, remote model, or remote code loader. It makes no network requests of its own.

The extension does not access:

  • your browsing history, bookmarks, downloads, or open tabs outside the supported sites;
  • your Google account, email, contacts, or payment information;
  • files on your device outside the page content of a supported site;
  • keystrokes or clipboard contents outside a supported code editor.

4. Storage

Local preferences

The extension stores one preferences object in chrome.storage.local. It contains settings such as the master switch, per-platform and per-language toggles, popup behavior, theme, and debug-logging preference. It does not contain source code, identifiers, URLs, or page text.

Optional Chrome Sync

If you explicitly enable Sync settings, the same preferences object is mirrored to chrome.storage.sync. Chrome Sync is operated by Google and is subject to Google's terms and privacy policy. Leetcomete does not operate the sync service and does not receive the synced data. Disabling sync removes the extension's synced copy while keeping the local copy.

Session status

The extension may keep short-lived status information in chrome.storage.session so the toolbar popup can show the detected platform, editor, language, and extension state for the current tab. This information is cleared when the tab closes or navigates and is not persisted across browser sessions.

5. Permissions and site access

The extension requests only the storage permission. It does not request tabs, history, bookmarks, cookies, webRequest, or <all_urls>.

Content scripts run only on the following domains, as declared in the extension manifest:

  • leetcode.com, www.leetcode.com, leetcode.cn, www.leetcode.cn
  • geeksforgeeks.org, www.geeksforgeeks.org, practice.geeksforgeeks.org
  • hackerrank.com, www.hackerrank.com
  • codeforces.com, www.codeforces.com, m1.codeforces.com, m2.codeforces.com
  • codechef.com, www.codechef.com
  • atcoder.jp
  • exercism.org, www.exercism.org

On those domains, the extension reads editor content to provide completion and detects the selected language. It does not read unrelated form fields, passwords, or messages.

6. Data sharing and sale

Leetcomete does not sell, rent, trade, or share data with third parties. There are no advertising partners, data brokers, or analytics providers. Because no data is collected, there is no data to disclose, transfer, or delete on a server.

7. Retention

  • Source text and indexes: held in memory for the current page and discarded when the index is evicted, the editor session ends, or the tab closes.
  • Local preferences: retained until you reset the extension, clear extension storage, or uninstall the extension.
  • Synced preferences: retained in Chrome Sync until you disable sync, clear the synced data, or uninstall the extension.
  • Session status: cleared on navigation, tab close, or browser restart.

8. Security

The extension is packaged as a Manifest V3 extension. All executable code is included in the package; it does not load remote scripts, use eval, or request broad host access. The page bridge runs in the page's main world to access editor APIs, while the isolated content script owns extension storage access. Source text does not cross that boundary.

9. Children

Leetcomete is a developer and study tool. It is not directed to children under 13 and does not knowingly collect information from children.

10. Changes to this policy

If the extension's data practices change, this page will be updated and the change will be reflected in a new extension version and Chrome Web Store listing. The effective date at the top of this page identifies the current version.

11. Contact

For privacy questions, use the support contact published on the Leetcomete Chrome Web Store listing.

12. Chrome Web Store disclosure

Leetcomete's use of information is limited to providing its single purpose: local code completion on supported code-editor pages. The extension does not use or transfer user data for purposes unrelated to that single purpose, and it does not use or transfer user data to determine creditworthiness or for lending purposes.
