Privacy and diagnostics

The extension has no network code and never transmits source code.

  • Lexing, scope analysis, type inference, and ranking all run in the page.
  • Only preferences are stored, in chrome.storage.local. Sync is opt-in.
  • No account, API key, analytics, remote model, or third-party server is used.
